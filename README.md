# TextLab

Локальное приложение для Windows для регистрации и анализа текстового ввода по предоставленному техническому заданию. Интерфейс, подсказки и отчеты на русском языке. Интернет, учетная запись и сервер не требуются.

## Запуск

Откройте **`dist\TextLab.exe`** или **`Запустить TextLab.cmd`**. Готовый EXE включает Python и Tk; отдельно устанавливать их не требуется.

Из исходного кода (Python 3.11+ с Tkinter, без сторонних библиотек):

```powershell
python run.py
```

Для отдельной папки данных:

```powershell
python run.py --data-dir "D:\Research\TextLab"
```

## Проведение сессии

1. Введите возраст, пол, ведущую руку, навык слепой печати, усталость и стресс по шкале 0–10, время суток, сведения о кофеине и седативных веществах, примечания. Пустой ID автоматически заменяется UUID; ручной ID должен быть уникальным в архиве.
2. Задайте название листа и инструкцию участнику. Выберите сплошной текст или карточки. В режиме карточек выберите несколько тем из каталога и/или добавьте свои, по одной на строку.
3. При необходимости задайте время в минутах, целевое число символов или слов. Ноль отключает соответствующий лимит; при нескольких ограничениях действует первое достигнутое. Лимиты относятся ко всему листу, а не к каждой карточке. Пороги микро- и макропауз можно изменить.
4. Нажмите **«Начать сессию»**. Вводите текст в редакторе. Доступны выделение мышью и клавиатурой, удаление, Ctrl+C/X/V, Ctrl+Z, Ctrl+Y. Tab вставляет табуляцию. Можно возвращаться к любой карточке; текст каждой сохраняется отдельно.
5. **«Приостановить»** исключает время перерыва из знаменателей скорости. При уходе из редактора запись приостанавливается автоматически; для возобновления нажмите **«Продолжить»**. Возврат в окно сам по себе запись не возобновляет.
6. Нажмите **«Завершить»**. При достижении лимита отчет открывается автоматически. Финальное нажатие может остаться без keyup и будет отмечено как незавершенная пара. Вставка целого фрагмента или слова может превысить целевой объем: введенный текст сохраняется целиком.
7. В отчете доступны весь лист и отдельные темы, график скорости, гистограмма пауз, сравнительная таблица и итоговые тексты. Экспорт всегда включает **весь лист**, независимо от выбранного фильтра темы.

Настройки листа можно сохранить кнопкой **«Сохранить протокол»** и повторно загрузить при создании следующей сессии. Профили участников в шаблоны протоколов не входят.

## Экспорт и хранение

- **HTML** — автономный человекочитаемый отчет с профилем, настройками, метриками, SVG-графиками, текстами и формулами. Откройте в браузере; для PDF используйте печать → «Сохранить как PDF».
- **JSON** — основной исследовательский формат: полный профиль, протокол, все временные метки и события, изменения текста, интервалы активности, итоговые тексты, сводные и тематические расчеты. Его достаточно для повторного анализа.
- **CSV** — одна строка на событие; UTF-8 с BOM, разделитель `;`. В `payload_json` сохранена исходная запись без потери полей. Текстовые значения с признаками формул экранируются для безопасного открытия в табличных редакторах.

По умолчанию база находится в **`%LOCALAPPDATA%\TextLab\textlab.sqlite3`**. Путь также показан в окне программы. Запись выполняется в отдельном потоке, приблизительно раз в секунду, с дополнительным сохранением при смене темы, паузе и завершении. После сбоя доступен последний успешно записанный снимок со статусом «Прервана»; несохраненные события последнего интервала могут быть потеряны. Продолжение оформляется новой сессией. Архив позволяет искать сессии по ID и названию и повторно открывать отчеты.

Для резервной копии закройте приложение и скопируйте папку данных. Программа не отправляет данные по сети и не перехватывает клавиатуру в других приложениях. База и экспорты не зашифрованы: храните их в папке с доступом для исследовательской группы.

## Что измеряется

- Скорость CPM считается по вставленным с клавиатуры символам, включая пробелы и повторно набранные исправления. WPM = CPM / 5. Вставки из буфера и undo/redo не увеличивают эти показатели; итоговые объемы включают их.
- Пауза — интервал между соседними текстовыми или редактирующими нажатиями внутри одного активного отрезка. По умолчанию микропаузой считается 300–1999,999… мс, макропаузой — от 2000 мс.
- Отрицательный Flight Time означает перекрытие нажатий. Неполные пары не включаются в распределение Hold Time.
- Процент исправлений — отношение числа удаленных к числу всех вставленных символов, а не доля орфографических ошибок.
- Индекс когнитивных задержек описывает долю времени макропауз. Сам по себе он не определяет когнитивную нагрузку, диагноз или психоэмоциональное состояние.
- Метки фиксируются монотонными часами при доставке события приложению. Единица наносекунда не означает наносекундной физической точности: задержки ОС, клавиатуры и GUI требуют отдельной аппаратной валидации для конкретного эксперимента.

## Разработка и проверка

```powershell
python -m unittest discover -s tests -v
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

Скрипт сборки создает локальное окружение `.venv`, устанавливает PyInstaller, выполняет тесты и создает `dist\TextLab.exe`. Для сборки нужен интернет, для готового приложения — нет. GUI-тестам нужна доступная графическая сессия.

Структура проекта:

| Файл | Назначение |
| --- | --- |
| `textlab/core.py` | Состояния сессии, события, метрики, анализ по темам |
| `textlab/app.py` | Интерфейс Tk, редактор, графики и архив |
| `textlab/storage.py` | Фоновая запись SQLite и восстановление |
| `textlab/export.py` | HTML, JSON, CSV и встроенная методика |
| `textlab/runtime.py` | Блокировка одновременного доступа приложений |
| `tests/` | Расчетные, интеграционные и GUI-тесты |
